# 项目目标

`goals.md` 是项目目标、范围和成功标准的唯一事实源。

## 项目愿景

为 AI 智能体提供一套可复用、可校验、可跨会话恢复的项目状态与交付规范，让多智能体协作、老项目接入和项目级技能约束都能落到仓库文件中。

## 当前范围

### In Scope Now

- 待补充
- 维护 `SKILL.md`、`README.md` 和 `STATE-MODEL.md` 的一致协议
- 提供可直接运行的初始化、声明写入和校验脚本
- 为新项目和老项目都建立统一的 `.claw/`、`docs/specs/`、`README.md` 和 `AGENTS.md` 接入方式

### Out Of Scope Now

- 面向特定技术栈的业务模板
- 通用代码生成框架或项目脚手架

## 成功标准

| 维度 | 指标 | 目标值 |
|------|------|--------|
| 功能 | 新项目初始化完整度 | 自动生成 `.claw/`、`docs/specs/`、`README.md`、`AGENTS.md` |
| 质量 | 协议一致性 | 协议、脚本、示例和校验器保持同步 |
| 性能 | 启动成本 | 接入步骤在一次初始化脚本内完成 |
| 业务 | 多智能体可恢复性 | 新接手智能体能从仓库文件判断技能要求并继续推进 |

## 约束

- 时间约束：技能协议演进需要保持文档和脚本同步发布
- 技术约束：尽量使用仓库内现有 bash/python 工具，不引入重依赖
- 合规约束：项目级声明必须明确 GitHub 安装来源
- 资源约束：保持技能主体和示例文件简洁，避免上下文膨胀
