# 项目目标

## 项目愿景

构建一个面向中小团队的内部协作门户，支持统一登录、消息通知和基础报表能力。

## 当前范围

### In Scope Now

- 邮箱密码登录
- 团队成员管理
- 基础消息中心
- 日常运营报表

### Out Of Scope Now

- 第三方 SSO
- 复杂审批流
- 多租户账单系统

## 里程碑

### MVP

- [x] 用户注册与登录
- [x] 基础权限模型
- [ ] 团队管理页面
- [ ] 登录失败告警

### V1

- [ ] 消息中心
- [ ] 报表导出
- [ ] 管理员审计日志

### Later

- [ ] 第三方身份集成
