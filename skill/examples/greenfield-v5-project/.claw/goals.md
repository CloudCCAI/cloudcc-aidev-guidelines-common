# 项目目标

## 愿景与用户

为需要搜索共享笔记的产品团队构建一个小型团队笔记 API。

## 范围

- 范围内：创建、编辑、列出和搜索文本笔记。
- 范围外：计费、移动客户端和富文本协作。

## 成功标准

- 计划的 API 契约覆盖四项范围内操作。
- 实现开始前，记录本地开发和验证命令。

## 约束与非目标

- 从一个由 PostgreSQL 支持的可部署服务开始。
- 第一个真实交付需求确认前，不创建任务。
