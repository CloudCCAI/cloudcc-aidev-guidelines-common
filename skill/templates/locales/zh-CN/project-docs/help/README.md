# 产品帮助与使用手册

此目录是 **{{PROJECT_NAME}}** 面向用户的产品帮助文档和使用手册的统一入口。

## 适合存放的内容

- 产品简介与适用用户。
- 快速开始、访问方式和初始化配置。
- 按用户任务组织的操作步骤。
- 页面、字段、操作和权限说明。
- 示例、预期结果、限制条件与常见问题排查。
- 与版本相关的行为和发布使用说明。

## 编写规则

- 从用户视角编写，只记录已经确认的产品行为。
- 按产品模块或用户任务拆分文档，并在本 README 中维护索引。
- 禁止写入密码、令牌、客户隐私数据或仅限内部的运维密钥。
- 未验证的行为必须标记为 `pending verification`。
